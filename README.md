# Plataforma DevGenn - Credencial Digital Colombiana

Este proyecto consiste en el diseño y desarrollo del primer modelo de **Credencial Digital** para los integrantes del equipo de la empresa **DevGenn**, basado en la estructura de la cédula colombiana real. 

El diseño ha sido construido bajo los estándares solicitados por el departamento de UX, garantizando una distribución elegante, limpia y organizada.

---

## 🎯 Objetivo del Proyecto
Construir una credencial digital completamente centrada en la pantalla utilizando **únicamente HTML5 semántico y CSS3 personalizado**, sin el uso de librerías ni frameworks externos, y aplicando principios de diseño fluido (sin media queries).

---

## 🚀 Tecnologías Utilizadas
* **HTML5** (Estructura 100% semántica)
* **CSS3** (Box Model, Flexbox nativo, Posicionamiento y Gradientes)
* **Font Awesome v6.5.0** (Iconografía profesional)
* **Google Fonts** (Tipografía corporativa Poppins)
